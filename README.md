# 32-bit RISC-V Single-Cycle Processor

A 32-bit single-cycle RISC-V processor designed from scratch in SystemVerilog for executing RISC-V instructions.

## Instruction Types

The instruction types implemented in this project are:

- R-type
- I-type
- S-type
- B-type
- J-type
- U-type

## Features

- 32-bit ALU
- Register File
- Instruction Memory
- Data Memory
- Immediate Generator
- Branch Condition Unit
- Program Counter
- Control Unit
- Write-Back Unit

## Tools

- SystemVerilog
- Vivado
- RTL Simulation
